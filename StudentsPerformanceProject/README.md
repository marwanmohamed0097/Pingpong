# Students Performance Analysis

## Project Overview

This project analyzes students' exam scores in math, reading, and writing using Python.

## Analysis

- Average score for each subject
- Average scores by gender
- Average scores by test preparation course
- Top 5 and bottom 5 records by average score
- Records with an average score of 90 or higher
- Mean, median, standard deviation, and percentiles for each subject

## Tools

- Python
- Pandas
- NumPy
- Matplotlib

## Run the Project

Keep `StudentsPerformance.csv` in the same folder as `main_final.py`, then run:

```bash
python main_final.py
